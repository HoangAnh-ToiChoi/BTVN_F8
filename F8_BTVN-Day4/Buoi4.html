3. Tạo form đăng ký

💪 Tự code, tự làm, không bảo "AI" làm hộ – Chúc bạn hoàn thành tốt bài tập! 🚀

  • Tạo file form.html, có tiêu đề chính là “Register”
  • Sử dụng thẻ Semantic HTML5
  • Form gồm các trường: Sử dụng input với type phù hợp với từng trường
  • Bấm vào label cũng focus vào input tương ứng
  • Ẩn input chọn Avatar, thay vào đó hiển thị Avatar placeholder hình tròn, click vào placeholder cho phép chọn 1 ảnh 1 lần, chỉ hiển thị các định dạng ảnh khi chọn file.
  • Bỏ check chính tả tại các input nhập dạng text/email/phone…
  • Bỏ tự động hoàn thành (Auto complete) cho form
