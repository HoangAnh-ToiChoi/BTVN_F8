Kết nối API (Fetch, Async/Await) để hiển thị Danh sách và Chi tiết sản phẩm

1. Quản lý sản phẩm (DummyJSON)

💪 Tự code, tự làm, không bảo "AI" làm hộ – Chúc bạn hoàn thành tốt bài tập! 🚀

  • Kết nối API của DummyJSON để lấy danh sách 30 sản phẩm đầu tiên.
  • Thiết kế giao diện lưới sản phẩm rõ ràng, sạch sẽ, chuẩn Responsive.
  • Truyền ID sản phẩm qua đường dẫn URL dưới dạng Query Parameter (?id=x).
  • Trang chi tiết tự đọc tham số URL và gọi API chi tiết sản phẩm tương ứng.
  • Tích hợp nút quay lại trang danh sách sản phẩm mượt mà.
